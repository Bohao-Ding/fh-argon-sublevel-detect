# v2a 物理核结构性检验计划

## 1. 目标与证据边界

本轮只回答两个问题：

1. 单能级薄层模型在加入严格可达性约束后，能否同时表达低压无击板电流、峰谷位置与随拒斥电压变化的横向漂移；
2. 单能级通过后，把四个 Ar I 4s 激发能作为同一电子碰撞历史中的竞争通道，是否比单能级给出更好的、可解释的拟合。

本轮不进行鲁棒性、留出验证、bootstrap、选择门消融或论文结论更新。H4s 的训练集拟合只能作为结构可行性证据，不能单独证明实验分辨出了四个能级。

H4s 从已通过门的 H1 最优点加载形状相同的公共供给、传输和门控参数；能级平移与四个危险率份额仍从 H4s 自身初始化，结果中记录实际加载和跳过的张量。

## 2. 冻结假设

### H1：有效单能级

- 阴极供给：带饱和的 Child–Langmuir 型供给包络；
- 传输：均匀电场下的薄层主方程；
- 非弹性碰撞：一个可学习的有效激发能；
- 收集端：轴向能量—角度高斯选择门，并乘以严格可达性因子；当有效轴向到达能不为正时，击板电流严格为零。碰撞区有效电压降与阴极—收集区到达阈值分别参数化，因为两者对应不同空间区域；该拆分只在首轮共享偏置被逐曲线证据否定后启用。
- 高斯门宽度允许吸收未显式建模的能量、角度与仪器展宽；低压严格零值由可达性因子保证，不能再靠人为收窄高斯门获得。

### H4s：四个竞争能级

- 固定 NIST Ar I 最低四个 4s 能级的相对能量：11.548355、11.623593、11.723161、11.828072 eV；
- 只允许四个能级共享一个小的能量平移，以吸收接触电势/标定误差；
- 四通道在每一薄层内竞争发生，通道参数表示碰撞危险率份额，不是末端电流混合权重；
- 状态为碰撞计数向量 `(n1, n2, n3, n4)`，允许 `(1, 1, 0, 0)` 等混合历史。

## 3. H1 预注册放行门

所有条件必须同时满足：

| 指标 | 门槛 |
|---|---:|
| 平均曲线 NRMSE | ≤ 0.055 |
| 截止电压 MAE | ≤ 1.50 V |
| 最大单曲线截止误差 | ≤ 1.50 V |
| 原始零电流区域预测 MAE | ≤ 0.015 μA |
| 峰位置 MAE | ≤ 1.00 V |
| 谷位置 MAE | ≤ 1.25 V |
| 峰召回率 | ≥ 0.80 |
| 谷召回率 | ≥ 0.75 |
| 峰横向漂移 RMSE | ≤ 1.00 V |
| `Vr=0` 伪峰谷数 | 0 |

只有 H1 通过后才进行 H4s 正式拟合。最大 epoch 仅是上限；训练在平滑损失进入平台期后提前停止。

## 4. 数值实现与验证

- 对相同 `Va` 的五条曲线只计算一次碰撞传播，再映射到不同 `Vr`，避免重复计算；
- 热能采用 Gauss–Laguerre 求积，发射角采用半球通量加权 Gauss–Legendre 求积；
- 单元测试冻结概率守恒、混合历史非零、不可达区严格零电流、拒斥电压单调抑制和有限梯度；
- smoke test 只检查工程链路，完成后删除临时输出；
- 正式结果写入新的 `output/v2_*` 路径，不覆盖 v1 结果。

## 5. Material Passport

- 输入：`data/FHdata.xlsx`（哈希见 `data/provenance.json`）；
- 旧基线：`data/old_k1_prediction_points.csv`，只读；
- 模型族：`v2a-competing-history`；
- 常数来源：NIST Atomic Spectra Database 的 Ar I 4s 能级；
- 适用边界：低阶可微主方程，不是完整 Boltzmann 求解器或轨迹 Monte Carlo；解析截面只用于本轮结构检验，不能替代状态分辨的实验截面。
