# 严格物理前向模型与论文综合模型的自比较及修订方案

## 范围与术语

本文把 `v2l` 及其后继候选统一称为**严格物理前向模型**，把论文正文中的模型称为**综合模型**。这里的“严格”是相对概念：严格物理前向模型显式推进阴极供给、薄层内竞争碰撞历史、末次碰撞位置以及能量—角度收集门，但它仍是低阶可微闭合，不是第一性原理 Boltzmann 或轨迹 Monte Carlo 求解器。

本次结论来自现有结果与源码逐读，并补充了一次只读、CPU-only 的局部可辨识性诊断。未启动 CUDA，未重跑正式 H1/H4s，未做大规模鲁棒性实验。论文仓库保持只读。

## 总结判定

1. 严格物理前向模型并非“完全没有多能级效应”：H4s 的样本内平均曲线 NRMSE 从 `0.030528` 小幅降到 `0.030306`，条件 AIC/BIC 也下降；但它只通过 12/15 项形态审核，最低能级通道占 91.36%，重新产生假峰、假谷和起板提前，而且 1800 epoch 未进入平台。因此失败的准确含义是：**当前严格核没有给出四个 4s 通道可分辨、形态一致且收敛的证据**。
2. 该结果**不推翻论文当前已经收窄的主要主张**。论文声称的是：在同一综合响应核下，指定 H4s 相对 H1 获得内部、模型相对的条件性预测优势；论文已经明确否认逐级分辨、确认或唯一识别四能级。
3. 该结果构成重要的**模型类别敏感性反例**：综合模型中的 H4s 优势没有在当前严格输运闭合中复现。因此论文不能升级为“微观输运模型独立证实四能级共同参与”或“结论跨模型类别稳健”。
4. 下一步不应继续放宽常数通道权重来追求 H4s 拟合，而应使用可追溯的、能量依赖的四通道部分激发截面，并让 H1 使用同一截面的总和作为匹配对照。源码候选 `v2m` 已按此原则建立，但在四通道截面数据核验前没有科学训练结果。

## 两种模型实际在检验什么

| 维度 | 论文综合模型 | 严格物理前向模型 v2l |
|---|---|---|
| 目标 | 检验指定能级排列能否改善跨 `Vr` 条件预测 | 检验供给—碰撞—收集链能否生成完整电流形态 |
| 原子响应 | 四个确定性近周期响应函数加权叠加 | 每层四个激发通道竞争，推进混合碰撞计数状态 |
| 多次激发 | 每个通道独立出现 `nEj` 周期相位 | 允许 `Ei+Ej` 等混合历史，累计损失 `sum(nj*Ej)` |
| 通道强度 | 与能量无关的 softmax 权重；熵正则抑制坍缩 | 与能量无关的 softmax 比例乘同形解析截面；无防坍缩熵项 |
| 输运 | 用解析包络、阻尼、收集与经验后段项压缩 | 显式薄层主方程、末次碰撞矩、角孔径及场进程展宽 |
| 展宽 | 共享响应宽度约 2.90 V | 收集门宽约 3 eV，另有 `10.5 exp(-Va/32)` eV 的碰撞场展宽 |
| 主要比较 | 5 折 leave-one-`Vr`-out；留出曲线不单独校准 | 同一 805 点样本内拟合与事后形态门 |
| H4s 结果 | 平均留出 NRMSE `0.12918→0.12613`；4/5 折改善，`Vr=10 V` 反转 | 样本内 NRMSE 仅降 `0.000222`；12/15，91.36% 坍缩到最低通道 |

二者不是同一统计问题。论文结果是**指定响应模板的内部跨条件预测比较**；严格结果是**当前输运闭合下的样本内形态兼容性比较**。不能直接用一个结果的 NRMSE 数值否定另一个，也不能把二者拼成“两个独立实验均支持/均反对 H4s”。

## 问题一：为什么更物理的模型没有成功表现多能级性质

### 1. 物理卷积尺度远大于能级尺度

四个 NIST 4s 能级总跨度只有 `0.279717 eV`。v2l-H4s 的收集门宽已经达到约 `3 eV`，是能级跨度的 10.73 倍；固定碰撞场展宽在 `Va=20,40,60,80 V` 时分别约为 `5.62, 3.01, 1.61, 0.862 eV`，仍是跨度的 `20.1, 10.8, 5.76, 3.08` 倍。数据采样步长 `0.5 V` 也大于四能级总跨度。

因此，单次激发层面几乎不可能出现四个可见子峰。严格模型允许最多 6 次碰撞；第 6 次碰撞的最外侧累计损失差可增至约 `1.68 eV`，但同一碰撞次数下有 84 种四通道计数组合，能量损失形成稠密混合，再经场分布、初始能量、角分布和收集门卷积，细结构会被进一步填平。

### 2. 真实竞争历史会去相干，综合模型则主动保留相位模板

综合模型把每个 `Ej` 写成一列独立周期响应；第 `n` 次重复处的相位差按 `n(Ek-Ej)` 累积，然后四列响应在末端相加。该结构保留了每个能级的独立、相位锁定“指纹”，即使宽度大于首次能级间隔，也可能从后续复合峰形中获得微小预测收益。

严格模型的电子却可依次走过不同通道。`E1+E3`、`E2+E2` 等近简并历史共同进入同一电流观测，碰撞位置和角度也不同。随机分支和混合序列使相位信息自然去相干。因而“更严格”通常会降低细能级的宏观可辨识性，而不是自动增强它。

### 3. v2l 的通道截面定义仍不够物理

v2l 对四个通道使用同一个 Weibull 型阈值截面形状，只移动阈值，并乘以四个与电子能量无关的 softmax 比例。真实部分激发截面 `sigma_j(E)` 的幅值、近阈形状和随能量的变化可明显不同；固定比例会把四个通道压成几乎共线的危险率族。Magyar、Korolov 与 Donkó 的 Monte Carlo 工作使用总截面碰撞概率，并同时包含弹性散射、25 个激发能级和电离；Allan、Zatsarinny 与 Bartschat 的结果也直接表明最低四个 4s 态需要逐态、随能量和角度变化的截面描述。

此外，v2l 允许把四个 NIST 激发损失能量整体训练平移。最终公共平移约为 `-0.259 eV`。接触电势或场标定误差应作用于电子动能标尺，而不应改变原子的真实能量损失；这是“严格物理”名义下仍需修正的一处定义。

### 4. 当前 H4s 是近共线、未收敛问题，不只是训练时长问题

对现有 H4s checkpoint，在固定其余参数时沿三个独立 logit 对比方向做中心差分，得到预测雅可比奇异值约为：

`[0.147565, 0.002167, 0.000242] uA/logit`。

条件数约 `609.6`，三列相关系数均大于 `0.999`。这说明四通道权重主要只提供一个可见方向，其余方向几乎不可辨。只在线性邻域调整权重，残差 RMSE 也只能从 `0.073266` 降至 `0.072151 uA`，且所需对比参数步长极大。该诊断支持“结构近共线”，但它只是固定公共参数的局部诊断，不等同于 profile likelihood 或留出比较。

另一方面，正式 H4s 在第 1800 轮仍取得最佳损失，尚未进入平台，因此不能把当前 91.36% 坍缩解释为已充分收敛的物理通道率估计。结构不可辨识与优化未收敛同时存在。

### 5. 两种正则与验证制度会把权重推向不同方向

论文综合模型显式惩罚低熵权重，所以四个权重接近四分之一在一定程度上是先验结构；正文也已明确说明它不是四次独立探测。严格模型没有该熵约束，优化器可以通过坍缩为一个有效低能通道降低误差。一个得到近均匀权重、另一个得到单通道坍缩，并不构成对原子事实的直接矛盾；它们首先反映不同的核、正则和观测可辨识性。

## 问题二：严格模型会不会影响论文主要主张

### 不被推翻的部分

- 论文综合模型的已验证事实仍成立：H4s 在 5 个内部留出折中的 4 折优于 H1，平均 NRMSE 相对下降 2.36%，同时保留 `Vr=10 V` 反例。
- 论文核心方法论——先冻结假设、再做完整曲线预测、保留反例和非唯一性——不依赖严格模型必须选择 H4s。
- 论文已经把证据边界写到“指定四能级响应的内部、模型相对支持”，并明确否认逐级分辨、确认和唯一识别。严格模型的 H1 选择与这一边界兼容。

### 必须进一步限制的部分

- 不能把论文结果改写成“真实碰撞动力学要求四个 4s 通道”或“严格物理模型验证了共同参与”。
- 不能声称 H4s 优势跨模型类别稳健。现有结果恰好显示：综合响应核保留 H4s 的微小相位模板，当前严格输运核则没有产生可接受的四通道解。
- 如果未来使用核验后的部分截面、匹配 H1 对照和可比的留出协议后，严格模型仍稳定选择 H1，那么论文结论应进一步写成“综合响应核中的条件性预测优势”，而不宜把它直接提升为微观参与机制证据。

因此，严格模型目前更像一项有价值的**负对照/敏感性分析**，而不是论文主张的反证。它不改变现有主要结论的真假，但降低任何强物理解读的可信度，并说明模型类别依赖应被显式披露。

## 严格物理前向模型的剩余问题与修改优先级

| 优先级 | 问题 | 当前证据 | 修改方案 |
|---|---|---|---|
| P0 | 常数通道比例与共享截面形状 | 权重雅可比近共线；91.36% 坍缩 | 用逐态、能量依赖的部分激发截面直接构造危险率 |
| P0 | 训练平移真实 NIST 损失能量 | H4s 公共平移约 `-0.259 eV`；H1 有效损失能量约 `10.886 eV` | H4s 固定 NIST 损失能量；H1 保留有效损失尺度；把装置偏移留在动能/电势参数中 |
| P0 | H1/H4s 若用不同截面将无法公平归因 | 旧 H1 为解析截面 | H1 使用四条部分截面之和，H4s 使用同表分通道 |
| P0 | 缺少已核验的完整四通道截面表 | 当前仓库没有可作为证据的数据 | 数据来源、版本、单位、能级顺序和哈希通过后才训练 |
| P1 | 装置展宽由同一 H1 数据和形态门选出 | 63 点扫描、21 点通过；非独立验证 | 后续把装置参数固定于独立校准或训练折，留出折只预测 |
| P1 | 展宽远大于能级跨度 | 门宽 10.73 倍；碰撞展宽 3.08–37.5 倍 | 把它视为数据分辨率上限；不得靠正则强迫四通道非零 |
| P1 | 损失函数与形态门冲突 | 损失继续下降时假谷重现 | 使用“形态可行域优先、损失次优”的词典序 checkpoint 选择 |
| P1 | H4s 未平台且只完成一个正式初值 | best epoch=1800 | 保留动态早停；先单初值调核，核冻结后再做少量优化重启 |
| P2 | 多个连续参数贴近边界 | 门宽、截面上升/衰减、供给尺度接近上界 | 在新截面输入后重新做 profile/边界审核，不先扩大边界 |
| P2 | 末次碰撞位置只保留一阶矩，角散射为启发式混合 | 当前为低阶闭合 | 若 v2m-H1 仍失败，再引入逐态位置分布或能量依赖 DCS；不并行堆叠 |

## 已构建的 v2m 源码候选

`v2m-tabulated-partial-cross-sections` 只改变多能级比较所需的最小物理定义：

1. 外部 CSV 提供 `sigma_1(E)...sigma_4(E)`，并要求来源元数据、单位、能级顺序、阈下严格为零和 0–100 eV 覆盖；
2. H1 使用 `sigma_total(E)=sum_j sigma_j(E)` 推进一个有效碰撞通道；
3. H4s 使用同一张表的四个部分截面推进 `n→n+e_j`，总危险率自然为部分危险率之和；
4. H4s 的四个能量损失固定为 NIST 值，不再训练公共原子能级平移，也不再训练常数 softmax 权重；
5. H1/H4s 共享 v2l 的供给、装置展宽、碰撞层数、角孔径和收集门，因此后续差异主要来自单一有效损失与四种真实损失历史。

源码位于 `src/fh_transport/model_v2m.py` 与 `src/fh_transport/pipeline_v2m.py`，输入规范位于 `data/cross_sections/README.md`。缺少核验截面时，程序会主动拒绝 v2m 训练；当前没有用合成截面产出或保留科学拟合结果。

已完成的小范围验证均为 CPU：

- v2m 截面表模式、阈值校验、动态分支、质量守恒与有限前向测试；
- 1 epoch、4 薄层、2 次碰撞上限的 H1 工程 smoke，输出放在自动清理的临时目录；
- v2l-H4s 局部可辨识性脚本复现上述条件数与展宽比；
- 完整轻量单元测试共 `44 passed`；其中 v2m/v2l/停止策略定向测试为 `9 passed`。无 GPU 调用和持久 smoke 目录。

## GPU 空闲后的最小训练顺序

1. **截面数据门**：只接受完整四条 4s 部分积分截面；核对来源、数据库版本、单位、阈值、能级顺序、100 eV 覆盖与再分发条款。单一角度 DCS 或只有两个允许跃迁的表不能替代四通道积分截面。
2. **v2m-H1 单能级门**：从 v2l-H1 的公共连续参数初始化，只训练匹配总截面 H1；沿用动态平台停止与 15 项形态门。若 H1 未通过，只在 H1 内修改，不启动 H4s。
3. **H1 失败时的修改顺序**：先检查截面单位/归一化和 optical depth；再检查碰撞场展宽与总截面是否重复承担弹性输运；最后才考虑末碰撞位置分布和 DCS。一次只改变一个闭合。
4. **v2m-H4s 二次验证**：仅在 H1 通过后，用相同表、相同装置参数化、相同离散配置训练 H4s；动态停止达到平台才形成结论。禁止熵正则或最低通道占比门，因为那会预先写入“多通道存在”。
5. **结论门**：同时报告拟合误差、15 项形态、随 `Va` 变化的积分通道事件分数、收敛状态和局部可辨识性。H4s 只有在不破坏 H1 形态门且不依赖近共线权重方向时，才可称为严格模型中的多能级支持。
6. **与论文真正可比的阶段**：只有上述门通过后，再做同一 leave-one-`Vr`-out 协议。该阶段属于后续验证，不在本次 GPU 受限调测中运行。

对 `K=1...8` 的严格物理扫描也应改变定义：`K` 必须对应有数据支持的真实部分截面集合或预先定义的物理分组，而不是让优化器自由生成 1–8 个能量和常数权重。当前四条 4s 截面只足以支持 H1 与 H4s 的匹配检验；扩展到更高 `K` 需要引入 4p、其他激发和电离截面，属于新的物理范围。
