# H4s 部分激发截面输入

`v2m-H4s` 不再用可训练常数权重代替四个激发通道的截面。正式训练前需要在本目录放入一份经人工核验、可追溯到原始数据库或论文的数据表；当前仓库不附带推测或合成的科学数据。

CSV 必须包含：

```text
energy_eV,sigma_1_m2,sigma_2_m2,sigma_3_m2,sigma_4_m2
```

四列依次对应 `4s[3/2]2`、`4s[3/2]1`、`4s'[1/2]0`、`4s'[1/2]1`。能量网格必须严格递增、覆盖 0–100 eV；各截面必须非负，并在对应 NIST 阈值以下严格为零。

同名侧车文件 `<name>.metadata.json` 必须包含：

```json
{
  "schema_version": 1,
  "source_name": "数据库或论文及版本",
  "source_url": "https://...",
  "level_order": ["4s[3/2]2", "4s[3/2]1", "4s'[1/2]0", "4s'[1/2]1"],
  "energy_unit": "eV",
  "cross_section_unit": "m2"
}
```

建议首选可下载的 LXCat BSR/Hayashi 原始部分截面，并在使用前核对数据库版本、四列能级顺序、单位和再分发条款。只有两条允许跃迁截面的数据不能替代完整四通道输入。
