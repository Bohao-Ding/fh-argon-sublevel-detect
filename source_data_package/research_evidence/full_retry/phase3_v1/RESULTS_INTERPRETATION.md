# Phase 3 v1 结果解释

## 1. 可防守的主要结果

同一组五条阻滞曲线主要支持一个二维、非可分的周期响应结构，但不支持把它直接命名为两个物理碰撞通道。二维模型在原始分数、Hellinger、CLR 和 ILR 表示上分别改善 `5/5`、`4/5`、`4/5`、`4/5` 个留出块；中位相对改善分别为 `42.15%`、`40.94%`、`26.52%` 和 `20.93%`。

四个移动残差块长度下，所有表示的条件代理检验均保留多数块优势；最弱一项为 ILR、块长度 23，条件代理 `p=0.0030`。这支持“整体非可分结构”作为开发性结果，但不能覆盖下面的局部失败。

## 2. 两个必须保留的失败门

`G10_composition_robustness` 失败。CLR 和 ILR 的最差块相对改善分别为 `-14.25%` 和 `-9.08%`，越过预先冻结的 `-5%` 界限。Hellinger 的最差块为 `-4.80%`，仅贴近通过线。因此结论不是逐块、坐标无关的普遍优势。

`G14_endpoint_full_rule` 失败。删去 `Vr=10 V` 后仍有 `4/5` 块改善，中位改善 `31.40%`，但最差块为 `-24.83%`；只保留 `Vr={0,4,6}` 时最差块为 `-7.35%`。端点曲线对完整门槛是必要的，不能把多数块结果写成端点不敏感。

## 3. 周期、块边界和绝对充分性

rank-2 平均误差的 profile 最优周期为：原始分数 `11.45 V`、Hellinger `11.50 V`、CLR `11.45 V`、ILR `11.45 V`。先验 `11.55 V` 相对各自最优误差的比值依次为 `1.0074`、`1.0046`、`1.0064`、`1.0035`，均远低于冻结的 `1.10` 上限。结果不是由精确调到单一周期点产生。

三个留出块平移方案均保留至少 `4/5` 块改善和至少 `10%` 的中位改善。与五次趋势和最佳错周期模型比较时，各组成表示均有 `4/5` 块由 rank-2 同时胜出；共同失败的是第 1 块。该区间应作为教学材料中的反例，而不是从平均数中删除。

## 4. 注入回收的有效结论与无效结论

采用候选无关的 H1 残差、等信号 RMS 和四种噪声方案后，NIST 4s 总跨度的精确恢复率为 `0.0%–0.2%`。这支持一个条件性负结论：在当前数据网格、线性谐波模板、候选集合和经验残差下，NIST 尺度不可恢复。

但是，全候选边际选择仍有约 `81%–87%` 落在最大候选 `factor=12`。这说明最大跨度偏好不再来自“给不同候选配不同残差”这一旧设计，却仍存在于候选评分几何中。因此不能从整条恢复曲线推导 `2.24 eV` 一类分辨率界限，也不能称为装置标定。

## 5. 面向正文的最小主张

建议正文只主张：五条归档阻滞曲线在多个组成表示、周期和块划分下，主要呈现共同的二维非可分周期响应；该结果存在一个稳定的局部失败块，并依赖最高阻滞端点才能满足完整预测门槛。亚能级尺度在当前条件注入任务中不可恢复，说明本实验更适合教学性地展示“模型结构证据”和“物理可辨识性”之间的区别。

上述结论仍是同一归档数据上的内部开发结果。它不能替代正反向扫描、独立热循环、电压校准和冻结后的确认集。
